# Літера

Сайт для підготовки до НМТ з української літератури: теорія по темах, тести у форматі НМТ,
вогник за щоденні заняття, XP, досягнення та інтервальні повторення.

Статичний сайт без сервера. Увесь прогрес зберігається **в базі SQLite прямо в браузері**
(sql.js + IndexedDB), тому працює офлайн і нічого нікуди не надсилає.

## Як запустити локально

Через `file://` не запрацює (ES-модулі й service worker цього не дозволяють). Потрібен
будь-який локальний сервер:

```bash
python -m http.server 8123
```

Далі відкрий http://127.0.0.1:8123

## Як викласти на GitHub Pages

1. Створи порожній репозиторій на GitHub (наприклад `litera`).
2. У цій папці:

```bash
git remote add origin https://github.com/USER/litera.git
git push -u origin main
```

3. У репозиторії: **Settings → Pages → Source: Deploy from a branch → main / (root)**.
4. За хвилину сайт буде на `https://USER.github.io/litera/`.

Файл `.nojekyll` уже лежить у корені — він потрібен, щоб GitHub Pages не чіпав структуру папок.

Після кожного оновлення файлів **піднімай `CACHE_VERSION` у `sw.js`** — інакше в уже
встановленому застосунку залишиться стара версія.

## Як користуватись із телефона

Відкрити посилання → «Поділитися» → «На початковий екран». Тоді сайт стане застосунком
з іконкою, працюватиме офлайн, а нагадування приходитимуть надійніше.

## Структура

```
index.html            каркас сторінки
css/style.css         усі стилі
js/
  app.js              запуск, маршрути (#/home, #/topic/id, #/quiz/id, …)
  db.js               SQLite у браузері + збереження в IndexedDB
  store.js            XP, вогник, прогрес тем, інтервальні повторення
  notify.js           нагадування
  ui/                 екрани: home, lesson, quiz, quiz-engine, practice, stats, settings
content/
  index.js            каталог розділів і тем
  topics/*.js         матеріал кожної теми
sw.js                 офлайн-кеш і фонове нагадування
```

## Як додати нову тему

1. Створи `content/topics/моя-тема.js`:

```js
export default {
  summary: 'Один рядок про тему.',
  slides: [
    {
      kicker: 'Паспорт твору',
      title: 'Заголовок слайда',
      html: `<p>Текст. Виділення: <b>жирне</b>, <em>помаранчеве</em>.</p>
             <ul class="facts"><li><b>Жанр:</b> поема</li></ul>
             <div class="quote">Цитата<span class="quote__note">пояснення</span></div>`,
    },
  ],
  questions: [
    {
      id: 'моя-тема-q1',           // унікальний на весь сайт
      type: 'single',
      prompt: 'Питання?',
      options: ['А', 'Б', 'В', 'Г', 'Д'],
      answer: 1,                   // індекс правильного варіанта, від 0
      explain: 'Чому саме так.',
    },
    {
      id: 'моя-тема-q2',
      type: 'match',
      prompt: 'Установіть відповідність',
      left: ['1', '2', '3', '4'],  // завжди 4
      right: ['А', 'Б', 'В', 'Г', 'Д'], // завжди 5 — один зайвий
      answer: [2, 0, 4, 1],        // для кожного лівого — індекс правого
      explain: 'Пояснення.',
    },
  ],
};
```

Щоб додати до слайда відео, впиши в нього поле `video` — на слайді з’явиться плитка,
яка вантажить ютуб лише після натискання:

```js
{
  kicker: 'Розбір',
  title: 'Подивись, як це пояснюють',
  html: `<p>…</p>`,
  video: { id: 'XXXXXXXXXXX', title: 'Назва ролика', author: 'Канал', minutes: 12 },
}
```

`id` — це те, що стоїть після `watch?v=` у посиланні. Перевірити всі відео на живість:

```bash
node tools/check.mjs --videos
```

2. Додай рядок у потрібний розділ у `content/index.js`:

```js
{ id: 'моя-тема', title: 'Назва', author: 'Автор', icon: '📖', minutes: 12 },
```

3. Додай файл у список `SHELL` у `sw.js` — тоді тема кешуватиметься для офлайну.

Варіанти відповідей перемішуються автоматично при кожному проходженні, тому порядок
у файлі значення не має.

## Правила гри

| Дія | XP |
|---|---|
| правильна відповідь | +10 |
| тест теми на ≥ 80% | +25 |
| тест теми без помилок | +15 |

Вогник горить, поки є хоча б одна відповідь щодня. Тема вважається пройденою від 80%.
Питання, у яких були помилки, повертаються в розділ «Тренування» за графіком
інтервальних повторень (спрощений SM-2).

## Резервна копія

Налаштування → «Резервна копія» зберігає файл `.sqlite` з усім прогресом. Його можна
відкрити будь-яким переглядачем SQLite або відновити на іншому пристрої через
«Відновити з файлу».

## Що варто знати про нагадування

Браузер не дає статичному сайту надсилати сповіщення «за розкладом» без свого сервера.
Працює так:

- поки застосунок відкритий — спрацьовує таймер усередині сторінки;
- якщо сайт додано на головний екран і браузер це підтримує (Chrome на Android) —
  service worker перевіряє раз на пів доби, чи було заняття, і нагадує.

На iPhone фонові нагадування не працюють — там сповіщення прийде лише коли застосунок
відкритий. Якщо потрібні справді надійні нагадування, наступний крок — Telegram-бот.
