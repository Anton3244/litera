# Синхронізація між пристроями

Прогрес живе в браузері кожного пристрою окремо. Щоб телефон і комп’ютер бачили
одне й те саме, потрібен крихітний сервер — він лише зберігає файл під випадковим кодом.

Тут — Cloudflare Worker. Безкоштовного тарифу вистачає з величезним запасом
(100 000 запитів на добу; нам треба кілька на день).

## Що робить сервер

Нічого розумного: приймає JSON і віддає його назад за тим самим кодом.
Уся логіка злиття — у браузері, у `js/sync.js`.

## Як розгорнути

1. Зареєструйся на <https://dash.cloudflare.com> (безкоштовно, картка не потрібна).
2. **Storage & Databases → KV → Create namespace**, назви `LITERA`.
3. **Workers & Pages → Create → Worker**, назви `litera-sync`, натисни **Deploy**.
4. Відкрий Worker → **Edit code**, встав уміст `sync/worker.js`, збережи й задеплой.
5. Worker → **Settings → Bindings → Add → KV namespace**:
   - Variable name: `LITERA`
   - KV namespace: `LITERA`
6. Скопіюй адресу воркера, щось на кшталт
   `https://litera-sync.твій-акаунт.workers.dev`

## Сповіщення на інший пристрій (push)

Локальні нагадування працюють, лише поки застосунок відкритий або поки браузер
погоджується будити service worker. Push — другий канал: приходить, навіть коли
застосунок закрито, і дозволяє надіслати повідомлення з режиму створювача.

### Секрети воркера

Ключі VAPID уже згенеровано — вони не лежать у репозиторії й не потрапляють
у застосунок. Додай їх у Worker → **Settings → Variables and Secrets**
(тип **Secret**, не Text):

| Ім'я | Значення |
|---|---|
| `VAPID_PUBLIC` | публічний ключ (див. нижче) |
| `VAPID_PRIVATE` | приватний ключ |
| `VAPID_SUBJECT` | `mailto:` і твоя пошта |
| `ADMIN_TOKEN` | вигадай довгий рядок — це пароль до списку кодів |

Через `wrangler` те саме:

```
wrangler secret put VAPID_PUBLIC
wrangler secret put VAPID_PRIVATE
wrangler secret put VAPID_SUBJECT
wrangler secret put ADMIN_TOKEN
```

Якщо колись знадобиться нова пара ключів:

```
node -e "const{generateKeyPairSync}=require('crypto');const{publicKey,privateKey}=generateKeyPairSync('ec',{namedCurve:'prime256v1'});const b=x=>Buffer.from(x).toString('base64url');console.log('PUBLIC',b(publicKey.export({type:'spki',format:'der'}).subarray(-65)));console.log('PRIVATE',privateKey.export({format:'jwk'}).d)"
```

Після зміни ключів усі підписки доведеться зробити наново.

### Як воно працює

1. Пристрій із увімкненими нагадуваннями підписується на push і кладе свій
   endpoint на воркер під своїм кодом.
2. Адмін у режимі створювача (`#/dev`) вводить токен, бачить список кодів
   і надсилає повідомлення на потрібний.
3. Воркер кладе текст у чергу й будить пристрій **порожнім** push-сигналом.
4. Service worker прокидається, забирає текст із черги й показує сповіщення.

Текст навмисно не передається через push: тіло не шифрується, а так
повідомлення взагалі не проходить через сервіс Google чи Mozilla.
Якщо підписки ще немає, текст полежить у черзі (до тижня) і прийде,
коли застосунок відкриють.

### Про адмінський токен

Токен **не зберігається в коді** й не їде разом із сайтом. Він лежить лише
як секрет воркера, а на своєму пристрої ти вводиш його руками один раз —
далі він живе в локальній базі цього браузера. Це важливо: пароль до `#/dev`
захищає від випадкового заходу, але його хеш видно в коді, тому справжнім
замком він бути не може. Токен — може.

## Як увімкнути в застосунку

На **першому** пристрої: Налаштування → Синхронізація →
вставити адресу сервера → «Створити» код → «Синхронізувати».

На **другому**: вставити ту саму адресу, ввести **той самий код** → «Синхронізувати».

Далі досить натискати «Синхронізувати» на тому пристрої, з якого щойно займалась.

## Що з даними

- Журнал відповідей об’єднується: записи з обох пристроїв зберігаються всі.
  Нічого не затирається, навіть якщо займалась і там, і там того самого дня.
- Вогник, інтервали повторення й стан тем перераховуються з об’єднаного журналу.
- Код — це і є ключ до даних. Хто його знає, той бачить прогрес,
  тому нікуди його не викладай. Пароля немає навмисне: у застосунку немає акаунтів.
- Якщо кодом не користуватись понад рік, запис на сервері зникає.
  Дані на самих пристроях від цього не страждають.
- Підписка на сповіщення можлива лише після того, як власниця сама дала
  браузеру дозвіл. Зняти його можна там само — у налаштуваннях сайту.

## Якщо сервер не потрібен

Синхронізацію можна не вмикати взагалі. Тоді для переїзду між пристроями
є Налаштування → Дані → «Резервна копія»: зберегти файл на одному пристрої
й відкрити на іншому через «Відновити з файлу».
