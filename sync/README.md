# Синхронізація між пристроями

Прогрес живе в браузері кожного пристрою окремо. Щоб телефон і комп’ютер бачили
одне й те саме, потрібен крихітний сервер — він лише зберігає файл під випадковим кодом.

Тут — Cloudflare Worker. Безкоштовного тарифу вистачає з величезним запасом
(100 000 запитів на добу; нам треба кілька на день).

## Що робить сервер

Нічого розумного: приймає JSON і віддає його назад за тим самим кодом.
Уся логіка злиття — у браузері, у `js/sync.js`.

## Як розгорнути

1. Зареєструйся на <https://dash.cloudflare.com> (безкоштовно, картка не потрібна).
2. **Storage & Databases → KV → Create namespace**, назви `LITERA`.
3. **Workers & Pages → Create → Worker**, назви `litera-sync`, натисни **Deploy**.
4. Відкрий Worker → **Edit code**, встав уміст `sync/worker.js`, збережи й задеплой.
5. Worker → **Settings → Bindings → Add → KV namespace**:
   - Variable name: `LITERA`
   - KV namespace: `LITERA`
6. Скопіюй адресу воркера, щось на кшталт
   `https://litera-sync.твій-акаунт.workers.dev`

## Як увімкнути в застосунку

На **першому** пристрої: Налаштування → Синхронізація →
вставити адресу сервера → «Створити» код → «Синхронізувати».

На **другому**: вставити ту саму адресу, ввести **той самий код** → «Синхронізувати».

Далі досить натискати «Синхронізувати» на тому пристрої, з якого щойно займалась.

## Що з даними

- Журнал відповідей об’єднується: записи з обох пристроїв зберігаються всі.
  Нічого не затирається, навіть якщо займалась і там, і там того самого дня.
- Вогник, інтервали повторення й стан тем перераховуються з об’єднаного журналу.
- Код — це і є ключ до даних. Хто його знає, той бачить прогрес,
  тому нікуди його не викладай. Пароля немає навмисне: у застосунку немає акаунтів.
- Якщо кодом не користуватись понад рік, запис на сервері зникає.
  Дані на самих пристроях від цього не страждають.

## Якщо сервер не потрібен

Синхронізацію можна не вмикати взагалі. Тоді для переїзду між пристроями
є Налаштування → Дані → «Резервна копія»: зберегти файл на одному пристрої
й відкрити на іншому через «Відновити з файлу».
